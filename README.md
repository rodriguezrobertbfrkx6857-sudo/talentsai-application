# TalentsAI Application Package

用于 TalentsAI「大模型训练 / Agentic Coding / AI 评测」方向申请的完整作品包。

## Deliverables

- `FINAL/TalentsAI_Resume_FINAL.pdf` — two-page A4 resume
- `FINAL/TalentsAI_Resume_Page01.png` / `FINAL/TalentsAI_Resume_Page02.png` — visual QA renders
- `project/` — independently runnable public GitHub project, linked here as a Git submodule
- `resume/TalentsAI_Resume.html` / `resume/TalentsAI_Resume.css` — editable resume source
- `review/` — project QA, resume fact check, visual review and privacy audit
- `assets/` — the three project visuals in PNG and SVG form

## Public project

`https://github.com/rodriguezrobertbfrkx6857-sudo/ai-evaluation-benchmark-lab`

The project is local-first, has 30 authored cases across three tracks, a Python evaluator, 32 pytest tests, and a saved demo report. No API key or paid service is required.
